# Палата 13 — PSX Horror

Браузерная 3D хоррор-игра: 15 процедурно генерируемых этажей заброшенной больницы, пиксельный фильтр, пространственные звуки и оригинальные модели Blockbench.

## Запуск

Откройте `index.html` в браузере. Интернет не нужен: движок, модели и звуки встроены в HTML. WASD — движение, Shift — бег, мышь — обзор, E — двери, ЛКМ — топор.

## Разработка

Нужен Node.js 18+. Сборка не требует установки пакетов:

```sh
node scripts/build.cjs
node tests/smoke.cjs
```

Редактируйте исходники в `src`, а не сгенерированный `index.html`. Порядок объединения подсистем задаётся в `scripts/build.cjs`: на текущем этапе они разделены по ответственности и используют общее игровое состояние одной JS-сборки. При дальнейшей разработке их можно постепенно переводить на независимые ES-модули.

| Каталог | Ответственность |
|---|---|
| `src/core` | Общие константы |
| `src/world` | Генерация комнат и связей, геометрия, мебель, двери, аномалии |
| `src/entities` | Импорт Blockbench, анимации, ИИ, выбор монстров и сценарии встреч |
| `src/player` | Игрок, движение, HUD |
| `src/render` | Three.js, текстуры, свет, частицы, скримеры |
| `src/audio` | Звуки с направлением и затуханием, эмбиент |
| `src/game` | Ввод, переходы этажей, меню, игровой цикл |
| `assets/models` | Исходные `.bbmodel` с текстурами и анимациями |
| `assets/audio` | Исходные звуковые файлы |
| `assets/manifest.json` | Имена ресурсов для сборки |
| `vendor` | Встроенный Three.js |
| `tests` | Автоматические проверки генерации и сценариев |

## Правила встреч

- На опасный этаж назначается ровно один ключевой монстр: бабуля или многоручка. Бабуля может временно исчезать и возвращаться. На безопасном этаже противников нет.
- Количество рядовых монстров выбирается равномерно от 0 до 4. Мумия и два зомби — рядовые противники. Для каждой позиции распределение: 20% — зомби за дверью, 20% — зомби в шкафу, 20% — гуляющий зомби, 40% — мумия. Если нужная дверь или шкаф недоступны, зомби становится гуляющим.
- Гном: 5% при первом посещении каждой комнаты, без повторных проверок. Не входит в лимит монстров.
- Забег: 15 этажей. Финальная жёлтая дверь завершает прохождение; после победы или смерти отображается статистика.
- Типы этажей: обычный 35%, просторный зал 25%, длинный коридор 15%, безопасная зона 10%, жёлтые комнаты 5%, смешанная планировка 10%. Безопасная зона включает стойку с моделью регистратора, картины и автоматы с едой (E восстанавливает до 20 HP один раз на автомат).

Модели и звуки заменяются через `assets`, после чего нужно пересобрать `index.html`.
